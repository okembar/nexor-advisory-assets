Comment ajouter dans Gmail
1. Gmail → Réglages → Voir tous les paramètres → Général
2. Section "Signature" → Créer une nouvelle signature
3. Éditeur → bouton "</>" (code HTML) → Coller le code
4. Enregistrer les modifications
